Set up KinTouch, step by step

  1. 1
    Get a Lovense developer token In Lovense's developer dashboard, open Standard API and fill in the form. Its Callback URL box can't be left empty: put any placeholder address for now, you'll replace it with this app's address in step 3. Save, then copy your Developer Token.
  2. 2
    Allow KinTouch with that token Done if you can see this screen: Kindroid asked for "your token for api.lovense-api.com" when you allowed the app. Pasted the wrong thing? Tap Reset token (under STOP) and Kindroid asks for it again. Lovense didn't accept the token. Reset it and paste your Developer Token again.
  3. 3
    Paste this app's Callback URL into Lovense Back in Lovense's developer dashboard, replace the placeholder Callback URL with this address and save. It is this copy's own address: everyone's is different. Getting this app's address…
  4. 4
    Pair your toy in Lovense Remote Lovense Remote is Lovense's own app for your toy. Where will the toy connect?
    Pick one above for the steps.
  5. 5
    Link KinTouch to Lovense Remote Tap Make a code, then enter the code in Lovense Remote (on a phone you can also scan it). This screen says Connected when Lovense reports your toy. If it doesn't within a minute, tap "check connection".
  6. 6
    Play Use the controls and the chat below, or just talk to your Kin in Kindroid's own chat: it can start, ramp, pattern, run steps and stop your toy. STOP at the top always works.
