Vignette Prompt Partner

A Kindroid Apps screen for shaping a Vignette selfie prompt with the Kin whose one-to-one chat opened the app, or with the first Kin attached when opened from Apps. The person enters a scene idea, the app sends it to the Kin using Kindroid's one-time ask feature, and the answer appears in the app. The Kin answers knowing who it is and who the person is (their name and the backstory they gave it), but not their chat or its memories. Follow-up details are sent as separate requests with the short session transcript included. The app does not read chat history, save Kin memory, send messages into chat, or generate images. Open it from a Kin chat to target that Kin; the Apps page uses the first attached Kin. The person reviews and copies the prompt into Kindroid's selfie flow. It requires kin:read, and Kindroid may charge for each Kin request.

Added
- Rules: "Medieval fantasy (codex rules)" (the default) sends the codex rules to the Kin with each request (medieval fantasy style first; firelight, lamplight, sun and moon only; period clothing with two or three concrete details and leather boots or shoes; positive wording; "an empty scene" for a place with no people; Simplified Chinese past 2,000 characters). "General Vignette" sends only the Vignette guidance.
- The draft is checked as you edit it: light words, modern clothing words, wardrobe detail, empty places and length (the same checks as Vignette Prompt Workshop).
- The session (idea, conversation and draft) is kept in session.json, so you can pick up where you left off after closing the panel. Start over clears it.
- Save prompt keeps a draft in saved.json (up to 100). Use loads one back into the draft; Delete removes it.
- Copy for Kin Backup copies every saved prompt as a Kin Backup import file; paste it into Kin Backup's Import to add them to its prompt library, linked to the Kin with the same name.
